# Data Sources

This directory contains all data for the RAG research project.

## Directory Structure

### `raw/` - Original Downloaded Data
Never modify files in this directory. All data here should be reproducible from source.

#### `raw/wikipedia/`
- **Source:** HuggingFace datasets - Wikipedia 20220301.en
- **File:** `wikipedia_500.json` (or `wikipedia_1000.json`)
- **Content:** Clean Wikipedia article text
- **Size:** ~30 MB for 500 articles
- **Generated by:** `src/corpus/download_wikipedia.py`

#### `raw/arxiv/`
- **Source:** arXiv API (cs.AI, cs.LG, cs.CR, cs.CL)
- **File:** `arxiv_150.json`
- **Content:** Paper abstracts with metadata
- **Size:** ~2 MB
- **Generated by:** `src/corpus/download_arxiv.py`

#### `raw/synthetic/`
- **Source:** Programmatically generated
- **File:** `synthetic_50.json`
- **Content:** FAQs, policies, technical docs
- **Size:** <1 MB
- **Generated by:** `src/corpus/create_synthetic.py`

---

### `processed/` - Processed Data
Generated from raw data. Can be regenerated if deleted.

- **`complete_corpus.json`** - Combined all raw sources
- **`chunked_corpus.json`** - After chunking (optional intermediate)
- **`corpus_stats.json`** - Statistics about the corpus

---

### `attacks/` - Attack Patterns
Malicious instructions for testing RAG defenses.

- **`static_attacks.json`** - 100-150 basic attack patterns
- **`adaptive_attacks.json`** - 150-200 evolved attacks

---

### `benign/` - Legitimate Queries
Normal user queries for false positive testing.

- **`benign_queries.json`** - 200-300 legitimate questions

---

### `cache/` - Downloaded Models
HuggingFace model cache (~2 GB, reusable)
